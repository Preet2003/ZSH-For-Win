Why it was made

On macOS and Linux, a great shell setup is common. On Windows, developers still spend evenings hand-editing $PROFILE, wiring PSReadLine, themes, completions, and plugins - then lose that setup on the next machine.

WinZSH exists so Windows feels first-class: one Setup.exe, managed profile hooks, a nested zsh-for-win session, and a single winzsh binary for install, themes, plugins, sync, and updates. Your stock PowerShell stays stock until you opt in.

Everything included

Built as a DX layer over PowerShell - not a new shell.

  • Prompt & themes

    Path + git-aware prompt. Themes like modern, powerline, catppuccin, tokyo-night.

  • Autosuggest & syntax

    Ghost suggestions (RightArrow / Ctrl+F). Syntax colors via PSReadLine.

  • Completions

    Lazy packs for git, docker, kubectl, npm, terraform, ssh, aws, az, and more.

  • Plugins

    First-party packs plus a SHA-256 community registry (plugin search/add).

  • Local AI

    Opt-in explain, ask, check, alias - offline heuristics, no API keys.

  • Sync & update

    Export settings across machines. Self-update from GitHub Releases or from source.

  • Multi-shell bridges

    CMD launcher plus experimental Nu / Bash bridges into nested PowerShell.

  • Background agent

    Same binary: compact history, refresh registry cache, optional update checks.

Install in minutes

1. Download

Get WinZSH-Setup-x86_64.exe from the latest GitHub Release.

Download Setup.exe

2. Run Setup

Double-click, or silent install:

.\WinZSH-Setup-x86_64.exe setup -y

3. Open a new tab

Start a fresh PowerShell window so PATH and profile refresh, then:

zsh-for-win
Get-WinZshInfo
exit

Publish the download (first time)

The Download button only works after you create a GitHub Release and upload the exe:

  1. Build locally: ./scripts/release/package.ps1
  2. Open Create a new release
  3. Tag v0.1.0, upload dist/WinZSH-Setup-x86_64.exe (and optionally the other dist files)
  4. Publish release - then the download URL works
  • winget (when published): winget install --id WinZSH.WinZSH -e
  • From source: clone and run ./scripts/install-from-source.ps1

Requires Windows 10/11 (x64). PowerShell 7 recommended.

How to use

Everyday flow

zsh-for-win              # enter WinZSH
winzsh theme set modern
winzsh plugin add git
winzsh plugin add docker
winzsh ai enable
winzsh ai check "git push --force"
exit                     # back to stock PowerShell

Management CLI

  • winzsh doctor - health checks
  • winzsh status - install / version
  • winzsh theme list|set - themes
  • winzsh plugin search|add - plugins
  • winzsh sync push|pull - settings sync
  • winzsh update - self-update
  • winzsh shell list - multi-shell bridges
  • winzsh agent start - background maintenance

Full cheat sheet lives in the repo: docs/essential-commands.md.

FAQ

Is WinZSH a new shell?

No. It is a DX layer over PowerShell. Stock PowerShell stays available; WinZSH activates with zsh-for-win.

Do I edit my PowerShell profile?

No. Setup/install manages a marked hook block automatically.

Is AI free / private?

Yes. Local offline heuristics only - no cloud provider, no API key requirement.

Why did Download show 404?

That URL only exists after a Release asset named WinZSH-Setup-x86_64.exe is uploaded to this repo. Until then, use from-source install or publish a release.

Where is the source?

github.com/Preet2003/ZSH-For-Win - MIT OR Apache-2.0.
